# Live Coding Summary

## Setup

1. To install dependencies, run 
    ```
    npm install
    ```
2. To create and initialize the database, run
    ```
    node src/scripts/DANGER_sync_db.js
    ```
3. To start the application, run 
    ```
    npm run dev
    ```
